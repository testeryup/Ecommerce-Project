# Tổng quan về đồ án
Nền tảng thương mại điện tử Octopus toàn diện chuyên về giao dịch các loại tài khoản trực tuyến phổ biến như Facebook, Netflix, Spotify, và các dịch vụ số khác.
# Thành viên
- Nguyễn Mạnh Đạt
- Trần Minh Hiền
# Chi tiết
- CRUD Product
- CRUD SKU
- CRUD Category
- CRUD Promo
- Có cơ chế nạp tiền và rút tiền, tích hợp PayOS và webhook để nạp tiền tự động
- Đăng nhập dùng JWT
- Mua hàng...
- Admin có thể ban/unban tài khoản nếu vi phạm
- Deploy lên Vercel, Render
